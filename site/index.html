m.  Mason

A home for all your Claude Code sessions

An ADHD-friendly, calm, and organized-by-default replacement for the Claude app.
Add persistent notes, rename windows, and easily spin off ideas into new chats. Customize your window view, never miss a session that needs you, and easily quiet everything that you don’t want to pay attention to.

New sessions created in Mason are automatically nested into projects based on their topics, and sessions in a git worktree join their main project.

Download and install

You need a Mac with Apple silicon, Claude Code, Homebrew, and Node.js 20 or newer. Mason builds on your own machine, so it takes a couple of minutes the first time.

Download Mason (.zip) View on GitHub
  1. Get the code. Unzip the download and move the folder to ~/mason, or clone it:
    git clone https://github.com/brittanyrferrero/mason.git ~/mason
  2. Install tmux and the dependencies.
    brew install tmux
cd ~/mason
npm install
  3. Turn on the hooks. This is what lights up "waiting on you" and adds /pause and /stash to Claude. Your settings file is backed up first.
    node scripts/hooks.mjs install
  4. Build and open Mason. This puts Mason.app in ~/Applications and opens it.
    scripts/install-app.sh
  5. Start working. Your existing Claude sessions appear right away. Press ⌃⌥M from anywhere to bring Mason forward, and ? inside it for the help card.
Updating, uninstalling, and the escape hatch

Updating. When there's a new version, a quiet Update button shows up at the top right of Mason with what's new. Click it and Mason rebuilds and reopens itself; running sessions keep going. You can also pull the latest code and run scripts/install-app.sh yourself.

Uninstalling. node scripts/hooks.mjs uninstall removes exactly what it added. Then delete Mason.app and ~/.mason.

Escape hatch. From any Terminal, tmux -L mason ls lists Mason's sessions and tmux -L mason attach -t <name> opens one.

How it's built

Mason has no network port. It reads what Claude Code already writes to disk and keeps its own data in one SQLite file. The only things that leave your Mac are the short summaries it asks Claude to write (you can turn those off) and a quiet check on GitHub for a newer version.
